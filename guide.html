资产线使用教程

把微信、支付宝的账单导进来，资产线会把你的总资产画成一条像股价一样的曲线：花一笔就往下走，进一笔就往上走。

不用注册打开网页就能用
数据只在你手机上账单在手机里解析，不上传
免费代码公开在 GitHub

1装到手机桌面

资产线是一个网页，装到桌面后用起来和 App 一样。

  1. 用 iPhone 自带的 Safari 打开 huatingshi.github.io/zichanxian。
  2. 点屏幕底部的分享按钮（方框加向上的箭头）。
  3. 往下找到「添加到主屏幕」，点「添加」。

桌面上会出现黑底红线的「资产线」图标。以后都从这个图标打开，全屏显示，没有地址栏。

以后都从桌面图标打开。从图标打开和在 Safari 里直接打开网址，数据是分开保存的，混着用会以为数据不见了。安卓手机用 Chrome 打开，菜单里选「添加到主屏幕」。

2导出账单

账单要先从微信、支付宝里申请导出，发到你的邮箱。导出后一般几分钟内收到邮件。

微信

我›服务›钱包›账单›右上角「…」›下载账单›用于个人对账

选好时间范围，填上邮箱。收到的邮件里是一个下载链接，下载得到一个 .zip 压缩包。解压密码会发到微信的「微信支付」消息里。

支付宝

我的›账单›右上角「…」›开具交易流水证明›用于个人对账

邮件附件是一个 .zip 压缩包，解压密码在支付宝的消息里。

中国银行

在中国银行 App 里申请电子版的账户明细，发到邮箱，附件是 PDF 或装着 PDF 的压缩包。中国银行的 PDF 目前只认得部分版式，认不出时会提示；这时可以先只导入微信和支付宝，银行卡的收支用「记一笔」补上。

把附件存到手机里

  1. 在手机邮箱 App（比如 QQ 邮箱）里打开那封邮件。
  2. 点开附件或下载链接，选「存储到文件」，存进 iPhone 的「文件」App。

3导入账单

  1. 打开资产线，点右上角的下载图标 ，弹出「导入账单」。
  2. 点「选择文件」，在「文件」App 里找到刚存的账单，可以一次选多个。压缩包不用自己解压。
  3. 点「解析」。有密码的压缩包会在下面出现密码框，分别填上它的解压密码，再点一次「解析」。
  4. 每个文件下面会显示认出了多少笔、新增多少笔。
  5. 第一次导入时，填一下现在的总资产：把微信零钱、支付宝余额和余额宝、银行卡余额加起来填一个数。点「保存」。

资产线会以你填的这个数为终点，按账单往回推算出过去每一天的资产，曲线就画出来了。

可以放心重复导入。已经导入过的交易会自动跳过，所以每个月导出一次、时间范围有重叠也没关系。

4看懂首页

  • 大数字是现在的总资产，下面一行是选中时间段里的涨跌，红色是涨，绿色是跌，和炒股软件的习惯一样。
  • 曲线每遇到一笔交易就跳一下。手指按住曲线左右拖动，可以看任意时刻的资产，以及那一刻是哪笔交易。
  • 曲线下面的 1周 1月 3月 1年 全部 切换时间范围。
  • 提醒：快到期的信用卡还款、快扣费的订阅会出现在这里。
  • 明细按天折叠，默认只显示最近 5 天，点某一天展开，最下面「显示更多」看更早的。

为什么有些交易写着「未计入」

资产线算的是总资产，钱在你自己的账户之间挪动不算涨跌，所以这些会自动排除：

标注例子
自己账户间转移零钱提现到银行卡、银行卡转进余额宝
还信用卡用储蓄卡还信用卡（消费时已经算过一次）
已在微信 / 支付宝账单里同一笔钱在银行流水和微信账单里各出现一次，只算一次
交易关闭、已退款没付成功的订单，或全额退款的订单

判断错了的话，点那笔交易，改成「计为支出」「计为收入」或「不计入」。

5随手记一笔

现金、没导入的账户，或者想马上记下来的花销，点底部中间的笔：

  1. 选「支出」或「收入」，填金额。
  2. 选分类；先写备注的话，比如「打车」，会自动选好「交通」。
  3. 点「保存」。

之后导入的账单里如果有同金额、两天内的同一笔，资产线会用账单里那笔替代手记的这笔，不会重复计算。

6校准余额

账单之外总有一些钱的变化：现金、利息、没导入的银行卡。时间久了，曲线上的数和你实际的钱会对不上。

这时点右上角的准星图标，填上实际的总资产。曲线会在这一刻记一笔「校准」，把差额补上。建议每次导入账单后都顺手校准一次。

7分类

底部「分类」页用圆环图显示钱花在了哪里，可以看本月、上月、近 3 月、今年，也可以切到「收入」。点某个分类，能看到这一类的每一笔。

分类是按商户名自动判断的，比如瑞幸、美团外卖归「餐饮」，滴滴归「交通」。分错了就点那笔交易改掉，勾上「以后同一商户都用这个分类」，以后就不用再改了。

8信用卡和分期

  1. 底部「还款」页，点「添加信用卡、花呗或白条」，填名称和每月还款日。
  2. 收到账单后点「填账单金额」，填本期应还。
  3. 有分期的话点「加分期」，填每期金额、总期数和已经还了几期。
  4. 还完后点「标记已还」，下次还款日和分期进度会自动往后走。

到期前 7 天会在首页「提醒」里出现，逾期会标红。网页没法给手机推送通知，想准时收到提醒，可以在 iPhone「提醒事项」里加一条每月重复的提醒。

9订阅

视频会员、iCloud、音乐会员这类自动扣费，在底部「订阅」页添加，会算出每月、每年一共花多少，扣费前 3 天提醒。

导入账单后，资产线会从账单里找出每月固定扣同样金额的商户，列在「账单里发现的订阅」，一键就能添加。

10备份和换手机

数据只存在这台手机的浏览器里，清除 Safari 的网站数据会把它删掉，换手机也不会自动带过去。

  1. 首页拉到最下面，点「下载备份」，选「存储到文件」，最好存到 iCloud 云盘。
  2. 在新手机上打开资产线，首页最下面点「从备份恢复」，选这个备份文件。

建议每个月备份一次。就算忘了备份，也可以从邮箱里重新导入账单，再校准一次余额。

11邮箱同步（进阶）

如果你有自己的云服务器，可以装一个小程序，让资产线直接从一个专门收账单的邮箱里取账单，省掉「存储到文件、选文件」这两步。解压密码仍然要手动填。

安装方法见 server/README.md。装好后在首页最下面「邮箱同步」里填上你自己服务器的地址和访问口令。访问口令不要告诉别人，拿到口令的人能取走你的账单文件。

12常见问题

我的账单会被别人看到吗？
不会。网页只是一段程序，账单在你手机上解析，记录存在你手机的浏览器里，不经过任何服务器。别人打开同一个网址，看到的是他自己的数据。
解压密码在哪里？
微信账单的在微信「微信支付」消息里，支付宝的在支付宝消息里，每次导出都不一样。
曲线上的数和我实际的钱对不上。
多半是有没导入的账户，或者有现金、利息。用右上角的准星图标「校准余额」填实际数字就行，详见第 6 节。
某笔交易算错了，或者重复了。
点那笔交易，在「是否计入曲线」里改成正确的选项。改过的交易会标「手动设置」，想改回来点「恢复自动判断」。
第一次打开看到的数字是谁的？
那是示例数据，左上角写着「示例数据」。导入你自己的账单或记第一笔后，示例就会被替换。
想从头开始。
首页最下面「清空数据」，会删除这台手机上的全部记录，无法撤销，需要的话先备份。
